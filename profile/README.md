👋 Welcome to 2BHIT
HTL Traun · Medientechnik · Class of 2BHIT

Welcome to the official GitHub space of 2BHIT, a class focused on media technology, programming, and digital creativity at HTL Traun, Austria.

This organization serves as a central place for our projects, experiments, learning resources, and collaborative work.

🎯 About Us

We are students exploring the world of technology, software development, and digital media.

Our work combines technical knowledge with creativity, problem-solving, and practical experience.

💻 Programming — Learning, developing, and experimenting with code.
🎨 Media Technology — Exploring digital design, multimedia, and creative technologies.
🔐 IT & Security — Developing an understanding of cybersecurity, privacy, and secure development.
🛠️ Projects — Turning ideas into practical applications and creative solutions.
🤝 Collaboration — Sharing knowledge and learning from one another.

You may find:

School projects and programming assignments

Documentation and learning resources
Tools and utilities developed by students

Each repository may have its own README and contribution guidelines.

🤝 Contribution Guidelines

Collaboration is an important part of what we do.

If you are a member of 2BHIT and want to contribute:

Read the repository's documentation and rules.
Follow the established coding and naming conventions.
Write clear commit messages.
Test your changes before submitting them.
Respect other contributors and their work.
Never upload passwords, API keys, or private information.

Please check the repository-specific RULES.md before contributing, where available.
